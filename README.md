## Config

Create a `config.py`:

```py
# YOUR WEBHOOK
YOUR_DISCORD_WEBHOOK_URL_HERE = 'YOUR_WEBHOOK_HERE'

# FOR BOT
CHANNEL_ID = 'YOUR_CHANNEL_ID_HERE'
BOT_TOKEN = 'YOUR_BOT_TOKEN_HERE'
```
